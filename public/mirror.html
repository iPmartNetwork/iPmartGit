🔄 میرور از GitHub

یک ریپازیتوری GitHub را به صورت محلی کپی کنید

آدرس کامل ریپازیتوری GitHub
توجه: برای میرور از GitHub نیاز به دسترسی اینترنت بین‌المللی (حداقل یک‌بار) دارید. پس از میرور، فایل‌ها به صورت محلی ذخیره می‌شوند و نیازی به اینترنت نیست. اگر دسترسی ندارید، می‌توانید فایل‌ها را دستی آپلود کنید.
